SITE DE BODAS DE ALGODÃO

O site agora é dividido em páginas. Não existe rolagem entre as partes.
Cada toque leva para a próxima página:

index.html -> fotos.html -> foto1 -> foto2 -> foto3 -> foto4 -> bodas -> final

Para trocar nomes e data, edite os textos em index.html.
Para trocar as fotos, substitua os arquivos dentro de img mantendo os mesmos nomes.
